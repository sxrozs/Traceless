## 📖 О проекте

**Traceless** — удобный деинсталлятор для Windows в духе Uninstall Tool.
Удаляет программы целиком, вместе с остаточными файлами и ключами реестра, не оставляя следов.

## ✨ Возможности

- 📋 **Список установленных программ** — обычные, системные, UWP/Store, скрытые
- 🧹 **Полное удаление** — вместе с остаточными файлами и ключами реестра
- ⚡ **Force Remove** — принудительное удаление «упрямых» программ
- 👁️ **Монитор установки** — показывает в реальном времени, что и куда ставится, с откатом
- 🔍 **Мгновенный поиск** и категории программ
- 📂 **Переход в реестр / папку** программы в один клик
- 🌐 **Поиск в интернете** — быстро найти инфу о неизвестной программе
- 📤 **Экспорт списка** в HTML / TXT
- 🗂️ **Пакетное удаление** и сортировка по дате / размеру
- 🚀 **Управление автозагрузкой**
- 💼 **Портативный режим**

## 🎨 Интерфейс

- Смена языка (RU / EN) и темы (тёмная / светлая)
- Понятный дизайн для обычного пользователя

## 📦 Установка

1. Скачай `Traceless.exe` из раздела [**Releases**](https://github.com/sxrozs/Traceless/releases/latest)
2. Запусти — установка не требуется (portable)

> ⚠️ Программа работает с реестром и системными файлами — антивирус может реагировать ложным срабатыванием.

## 🛠️ Сборка из исходников

Требуется **Qt 6** и компилятор C++ (MSVC / MinGW).

```bash
git clone https://github.com/sxrozs/Traceless.git
cd Traceless
qmake
make
```

Или открой проект в **Qt Creator** и нажми **Build**.
